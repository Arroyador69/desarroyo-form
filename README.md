## 🎯 **Flujo de Trabajo Recomendado**

### **1. Primera Configuración:**
```bash
# Clonar/descargar proyecto
cd desarroyo-form

# Inicio automático (configura todo)
npm run crm
```

### **2. Uso Diario:**
```bash
# Inicio rápido
npm start

# Ir a: http://localhost:3000/login.html
# Login: admin / admin123
```

### **3. Crear Contenido:**
1. **📂 Subir videos** → Dashboard → Videos → Clips
2. **🎨 Seleccionar plantilla** → Videos → Plantillas
3. **🎭 Generar guión** → Clic en "🎭 Guión"
4. **🎬 Crear video** → Videos → Generados
5. **🤖 Generar contenido viral** → IA Contenido
6. **📤 Publicar** → Redes sociales

## 🛠️ **Tecnologías Incluidas**

- **Backend**: Node.js + Express
- **Base de datos**: SQLite (sin configuración)
- **IA**: DeepSeek para chatbot y guiones
- **Videos**: FFmpeg + Sharp para procesamiento
- **Pagos**: Stripe para suscripciones
- **Frontend**: HTML5 + TailwindCSS + Alpine.js
- **Auth**: JWT + bcrypt
